- A auditoria é invocada com `Fase.VERIFICAR` apenas como rótulo de invocação (`# é leitura limpa; não há fase nova aqui`); o prompt emitido é o do molde, sem citar skill — o que mantém F7 e F6 coerentes apesar do reuso do enum.

Ambas as trocas preservam o que aqueles testes checavam.
